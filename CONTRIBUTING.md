# Contributing

Use a dedicated Python environment and follow the README installation notes. FFmpeg/FFprobe are required for media tests. Run `python -m pytest -q` before submitting a change.

Keep contributions focused and include a regression test for a demonstrated bug. Preserve read-only evidence retrieval, bounded output, half-open time ranges, explicit provenance and real review records. Changes to production classification need a separate labeled evaluation; generated fixtures do not establish model quality.

Update all four README translations when user-facing installation or behavior changes. Native report generation currently supports zh/en.

Preserve Apache-2.0 attribution and document modifications in UPSTREAM.md/CHANGELOG.md. Include only material you can redistribute. Never add API keys, private environment files, user videos, generated personal reports or model weights.

Publish changes through the repository owner's normal review process; installation or contribution instructions do not grant publication or paid-generation authority.
